# Application protocols: example specifications

Examples for [chapter 06, Application
protocols](https://heigvd-dai-26.github.io/chapters/06-application-protocols.html).
Each directory holds one protocol specification, written in Markdown
with [Mermaid](https://mermaid.js.org/) sequence diagrams. Read them on
GitHub, which draws the diagrams.

1. [The SMS protocol](sms-protocol): the worked example of the chapter,
   a model for your own specifications.
2. [The *"Guess the number"* protocol](guess-the-number): one possible
   solution of exercise 3.
3. [The *"Temperature monitoring"* protocol](temperature-monitoring):
   one possible solution of exercise 4.

Each specification is **one of the possible results**. Yours can make
other choices and be just as good, as long as every question of the
specification has an explicit answer.

To see the Mermaid source of a diagram, open the file and click
**Code** (or **Raw**) above it.
